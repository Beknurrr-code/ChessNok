# ♟️ Chessnok — оффлайн шахматный AI-тренажёр

**Chessnok** — это современное обучающее шахматное приложение с встроенным ИИ, задачами, учебником и игровыми режимами. Работает полностью оффлайн, в браузере. Подходит для новичков и продвинутых игроков.

## 🚀 Возможности

- ♟ Игра против локального ИИ (уровни сложности: от "очень лёгкий" до "очень сложный")
- 👥 Конструктор позиции: создавай свои позиции и начинай с них
- 📖 Интерактивный учебник по шахматам (4 главы)
- 🧠 ИИ-помощник: чат с анализом позиции и подсказками
- 📈 График оценки позиции по ходу партии
- 🧩 Подсказки и возможность отмены хода (если включено)
- 🌙 Полностью оффлайн и без регистрации

## 🖥 Запуск

1. Скачай проект или перейди на [GitHub Pages](https://Beknurrr-code.github.io/ChessNok/)
2. Открой `index.html` в браузере — всё работает локально.
